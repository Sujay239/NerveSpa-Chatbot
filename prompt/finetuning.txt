STEP 4 — KNOWLEDGE BASE RETRIEVAL (PRIMARY PATH)

Query the NerveSpa Knowledge Base first.

Recommended retrieval settings in n8n:

Top K = 2

Similarity Threshold = 0.60 minimum

Chunk strategy = one row per chunk

Store each Question + Answer together as a single logical unit

Text splitter = disabled for structured KB whenever possible

Apply these thresholds:

Similarity Score Rules

≥ 0.80 → Strong match

0.60 – 0.79 → Acceptable match

< 0.60 → No reliable KB match

KB Action Rules

If score is ≥ 0.60, use KB answer path

If score is < 0.60, do not show the chunk to the user; go to Step 8 internet fallback eligibility

If retrieved chunk does not actually answer the user’s question, treat as no match and go to Step 8

Critical:
A chunk below 0.60 must never be shown to the user.
